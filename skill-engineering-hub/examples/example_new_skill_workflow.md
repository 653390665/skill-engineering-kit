# Example: New Skill Workflow

User request:

> I want to create a skill for analyzing restaurant menu positioning.

Correct hub behavior:

1. Do not immediately generate files.
2. Produce Skill Brief.
3. Decide architecture: probably single skill + templates, not multi-skill.
4. Write Trigger Contract.
5. Write Output Contract.
6. Write Quality Test Plan.
7. Recommend skill-creator as next tool.

Incorrect behavior:

- Immediately generating SKILL.md and examples without defining triggers or failure modes.
