# Architecture Decision

## Problem
What capability or workflow is being built?

## Options considered

### Option A: Single skill
Use when the task has one main trigger and output type.

### Option B: Multiple skills
Use when stages have different triggers, outputs, or safety boundaries.

### Option C: Skill + role agents
Use when multiple perspectives are needed but the scenario is still one workflow.

### Option D: Skill + shared gates
Use when multiple skills need the same standards or safety rules.

### Option E: Skill + scripts
Use when deterministic checks or repeatable build/test steps are needed.
