# Trigger Contract

## Positive triggers
- "How should we create this skill?"
- "Audit this skill against our standard."
- "Prepare a pressure-test plan."
- "Interpret this pressure-test report."
- "Is this skill ready to release?"
- "How should skill-creator, writing-skill, and pressure-testing work together?"

## Negative triggers
- "Generate the complete skill now from this approved brief." → skill-creator.
- "Polish this README." → writing-skill.
- "Run these exact pressure scenarios." → skill-pressure-testing.
- "Use this business skill to analyze a project." → target business skill.

## Neighbor skills
| Neighbor | Difference |
|---|---|
| skill-creator | Creates files after planning is approved. |
| writing-skill | Edits and improves written docs. |
| skill-pressure-testing | Executes pressure tests and checks behavior. |
| skill-engineering-standard | Defines reusable standards and templates. |
