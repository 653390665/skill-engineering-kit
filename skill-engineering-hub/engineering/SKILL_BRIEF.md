# Skill Brief — skill-engineering-hub

## Skill name
- `skill-engineering-hub`

## Core promise
Coordinate the skill engineering lifecycle from planning to audit, pressure-test preparation, result interpretation, and release gate decisions.

## Target users
- Skill authors.
- Teams maintaining multiple skills.
- Users coordinating skill-creator, writing-skill, and skill-pressure-testing.

## Inputs
- A new skill idea, or
- an existing skill package/path, or
- a pressure-test report, or
- a release decision request.

## Outputs
- Planning artifacts.
- Standard audit report.
- Pressure-test brief.
- Optimization report.
- Release gate decision.

## Boundaries
This skill does not replace skill-creator, writing-skill, skill-engineering-standard, or skill-pressure-testing.
