# Output Contract

## Required outputs by mode

- New Skill Planning: Skill Brief, Architecture Decision, Trigger Contract, Output Contract, Quality Test Plan.
- Existing Skill Audit: compliance report with P0/P1/P2 fixes.
- Pressure-Test Preparation: scenario matrix and pass/fail rules.
- Result Interpretation: failure classification and optimization roadmap.
- Release Gate: release / patch / hold / rollback decision.
- Toolchain Flow: stage-by-stage process and responsibility matrix.

## Forbidden outputs

- Do not claim tests passed without inspection or results.
- Do not silently modify the target skill.
- Do not collapse standard, creator, writer, and pressure testing into one ambiguous role.
