# Priority Taxonomy

## P0 — release blocker

Fix before use or release.

Examples:

- invalid frontmatter;
- missing SKILL.md;
- unsafe behavior;
- wrong trigger that causes harmful activation;
- claimed test pass without evidence.

## P1 — stability blocker

Fix before team or public distribution.

Examples:

- trigger/output contract missing;
- examples contradict templates;
- release package contains local logs;
- pressure tests missing for critical routes.

## P2 — improvement

Useful but not blocking.

Examples:

- add more examples;
- improve README clarity;
- add optional scripts;
- add more regression scenarios.
