# Standard Check vs Pressure Test

## Standard check

Asks:

- Does the skill have the right design artifacts?
- Are triggers and outputs defined?
- Are boundaries documented?
- Are tests planned?

It can happen before creation, during creation, or before pressure testing.

## Pressure test

Asks:

- Does the skill behave correctly under realistic prompts?
- Does it route correctly?
- Does it avoid forbidden output?
- Does it pass regression and safety checks?

It happens after the skill exists.

## Combined report

A mature skill review should include both:

1. Engineering standard compliance.
2. Behavioral pressure-test results.
