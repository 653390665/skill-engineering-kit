# Pressure-Test Result Interpretation

Use this mode when test results already exist.

## Output

- summary of pass/fail;
- failure classification;
- root cause;
- affected standard artifact;
- required fix;
- regression test to add;
- release decision.

## Failure classes

- installability failure;
- trigger failure;
- route failure;
- output contract failure;
- evidence/hallucination failure;
- safety boundary failure;
- execution/task hardness failure;
- package cleanliness failure;
- documentation mismatch;
- regression from prior version.
