# Pressure-Test Preparation

Use this mode to prepare `skill-pressure-testing` inputs.

## Required output

- scenario matrix;
- happy path cases;
- missing info cases;
- negative trigger cases;
- adjacent skill confusion cases;
- safety/boundary cases;
- execution pressure cases;
- required patterns;
- forbidden patterns;
- pass/fail rules;
- regression seeds.

## Relationship to skill-pressure-testing

This hub prepares and organizes test design. `skill-pressure-testing` executes or validates the pressure run.
