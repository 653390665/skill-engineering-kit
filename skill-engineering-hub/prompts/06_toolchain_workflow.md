# Toolchain Workflow

Explain or design the workflow between:

- skill-engineering-hub;
- skill-engineering-standard;
- skill-creator;
- writing-skill;
- skill-pressure-testing.

## Core principle

- Standard defines the rules.
- Hub coordinates the workflow.
- Creator generates files.
- Writing improves documents.
- Pressure testing checks behavior, boundaries, and release readiness.

## Required output

- stage-by-stage workflow;
- handoff artifacts;
- responsibility matrix;
- when to use each tool;
- common failure recovery paths.
