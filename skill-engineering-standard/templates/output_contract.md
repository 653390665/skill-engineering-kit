## 4. Output Structures

Choose output structure based on user need:

| User Need | Output Structure |
|---|---|
| Explore idea | Question chain |
| Compare options | Decision matrix |
| Debate / co-create | Roundtable minutes |
| Validate business | Evidence table + tests |
| Write formal doc | Structured report |
| Execute task | Task card |
| Build code task | 13-section development task |

## 5. Evidence Labels

Every factual or strategic claim should be one of:

- User-confirmed
- AI deduction
- Assumption
- Unknown
- External fact requiring source / search

## 6. Quality Bar

A good output should be:

- specific
- actionable
- bounded
- evidence-aware
- not overconfident
- matched to the user's stage
